# TimeTracker

## Pobieranie i instalacja

1. Pobierz **TimeTracker-Setup.exe** z [najnowszego wydania](https://github.com/japanozi/TimeTracker-pobierz/releases/latest).
2. Uruchom pobrany plik. Instalacja nie wymaga uprawnień administratora — skróty pojawią się na pulpicie i w menu Start.

> **Brak podpisu cyfrowego.** Program nie jest podpisany, dlatego Windows może wyświetlić komunikat
> „System Windows ochronił ten komputer”. Wybierz wtedy **Więcej informacji → Uruchom mimo to**.

## Aktualizacje

Aktualizacje pobierają się automatycznie. Gdy nowa wersja jest gotowa, w programie pojawia się pasek z przyciskiem
**Uruchom ponownie i zaktualizuj**. Jeśli go pominiesz, aktualizacja zainstaluje się przy zamknięciu programu.

## Odinstalowanie

Ustawienia Windows → Aplikacje → Zainstalowane aplikacje → **TimeTracker** → Odinstaluj.
